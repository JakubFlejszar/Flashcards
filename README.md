# Flashcards

This is a Flashcards application where you can create and study flashcard sets.

## Features

* Creating flashcard sets
* Adding and managing flashcards
* Studying flashcard sets
* Tracking correct and incorrect answers
* Deleting flashcard sets

## Built with

* C#
* .NET 10
* SQL Server
* Microsoft.Data.SqlClient

## How to use

* Choose a menu option
* Follow the instructions
* Create or select a flashcard set
* Start a study session
* Answer the questions and check your results 👍
